English

개인정보처리방침

시행일: 2026년 11월 18일

요약

  • Desk Calendar는 내 PC에서 실행되며 Google과만 통신합니다. 개발자는 서버를 운영하지 않으며 사용자의 데이터를 받지 않습니다.
  • Google 데이터는 앱에서 내 캘린더와 할일을 보여 주고 편집하는 데에만 사용합니다.
  • 데이터를 판매하거나 공유하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다.
  • 로그아웃하면 로그인 토큰과 오프라인 사본이 PC에서 삭제됩니다.

1. 운영자

Desk Calendar(이하 “앱”)는 Desk Calendar Team(이하 “개발자”)이 만든 Windows 데스크톱 프로그램입니다. 이 방침은 앱이 어떤 정보에 접근하고 그 정보를 어떻게 사용·저장·보호하는지, 그리고 사용자가 무엇을 선택할 수 있는지 설명합니다. 이 웹사이트에도 적용됩니다.

2. 앱이 접근하는 Google 사용자 데이터

앱은 사용자가 Google 로그인을 누르고 Google 동의 화면에서 허용했을 때에만 아래 권한을 사용합니다. 로그인하지 않으면 로컬 모드로 동작하며 Google 데이터에 접근하지 않습니다.

권한(범위)데이터사용 목적
Google 캘린더
https://www.googleapis.com/auth/calendar		캘린더 목록, 캘린더 색상, 일정캘린더와 일정을 보여 주고, 사용자가 앱에서 일정을 만들거나 바꾸거나 옮기거나 삭제할 때 이를 반영
Google Tasks
https://www.googleapis.com/auth/tasks		할일 목록, 할일할일을 보여 주고, 사용자가 앱에서 할일을 만들거나 수정·완료·삭제할 때(직접 설정한 매월 반복 할일 포함) 이를 반영
기본 프로필
openid, email, profile		이름, 이메일 주소, 프로필 사진로그인한 Google 계정을 표시하고, 계정을 여러 개 추가했을 때 서로 구분

3. Google 사용자 데이터의 사용

앱은 Google 사용자 데이터를 앱에서 보이는 기능을 제공하는 데에만 사용합니다.

  • 캘린더, 일정, 할일 목록, 할일 표시
  • 사용자가 요청할 때 일정과 할일을 만들기, 바꾸기, 옮기기, 완료, 삭제
  • 사용자가 설정한 매월 반복 할일을 달마다 하나씩 만들기
  • 로그인한 계정 표시와 계정 전환

이 밖의 목적으로는 사용하지 않습니다.

4. 데이터 저장 위치와 보호

앱이 저장하는 모든 데이터는 사용자의 PC, %APPDATA%\com.desktop.deskcalendardock 폴더에만 저장됩니다.

  • Google이 발급한 로그인 토큰: Windows 데이터 보호 API(DPAPI)로 암호화하여, 해당 Windows 사용자 계정만 읽을 수 있습니다.
  • 캘린더, 일정, 할일 목록, 할일의 오프라인 사본: 인터넷이 끊겼을 때 보여 주기 위한 것입니다.
  • 설정, 추가한 계정 목록, 사용자가 설정한 매월 반복 할일 정보

앱은 암호화된 HTTPS 연결로 Google 서버와만 데이터를 주고받습니다. 로그인은 웹 브라우저에서 Google OAuth 2.0(PKCE)으로 진행되므로 앱은 Google 비밀번호를 알 수 없습니다.

5. 제3자 제공

개발자는 Google 사용자 데이터를 누구에게도 판매·대여·이전·공유하지 않습니다. 데이터는 사용자의 PC와 Google 사이에서만 오가며 개발자에게 전달되지 않습니다. 특히 다음과 같이 사용하지 않습니다.

  • 맞춤형 광고나 리타기팅 광고를 포함한 광고 목적의 사용이나 이전
  • 신용도 판단이나 대출 목적의 사용
  • 개발자를 포함한 사람이 데이터를 열람하는 것
  • 범용 AI·머신러닝 모델의 개발, 개선, 학습에 사용

Desk Calendar가 Google API에서 받은 정보를 사용하거나 다른 앱으로 전송할 때는 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 보관 기간과 삭제

PC에 저장된 데이터는 사용자가 지울 때까지 보관됩니다.

  • 계정 카드에서 로그아웃을 누르면 그 계정이 앱에서 빠지고, 로그인 토큰과 오프라인 사본이 PC에서 삭제됩니다.
  • 모든 데이터를 지우려면 앱을 종료한 뒤 %APPDATA%\com.desktop.deskcalendardock 폴더를 삭제합니다.

로그아웃만으로는 Google에 준 권한이 취소되지 않습니다. 권한을 취소하려면 Google 계정의 ‘서드 파티 앱 및 서비스’에서 Desk Calendar를 삭제하세요.

일정과 할일 자체는 사용자의 Google 계정에 보관되며, 앱을 지워도 삭제되지 않습니다. 이 데이터에는 Google 개인정보처리방침이 적용됩니다.

7. Google 계정 없이 사용하는 경우

로그인하지 않고 만든 일정과 할일은 같은 폴더에 PC에만 저장되며 어디로도 전송되지 않습니다.

8. 이 웹사이트

이 웹사이트는 GitHub Pages에 올린 정적 페이지이며 쿠키, 사용 통계, 추적 기능을 쓰지 않습니다. 다른 웹사이트와 마찬가지로 호스팅 서비스(GitHub)와 글꼴 서비스(jsDelivr)는 페이지를 전달하기 위해 IP 주소 같은 기술 정보를 받습니다.

9. 방침의 변경

이 방침을 바꾸면 이 페이지와 위의 시행일을 함께 고칩니다.
