Google 캘린더 · Google Tasks용 Windows 데스크톱 앱

한눈에 들어오는 달력,
가볍게 끝내는 오늘의 일.

Desk Calendar는 Google 캘린더 일정과 Google Tasks 할일을 Windows PC의 깔끔한 창 하나에 나란히 보여 줍니다. 브라우저를 열지 않고도 한 달을 훑어보고, 다가오는 마감을 챙기고, 다음 할 일을 바로 추가하세요.

Windows용 다운로드 Google 데이터 사용 방식

버전 1.3.0 · Windows 10, 11 (64비트)

기능

오늘 필요한 모든 것을 한 창에

Desk Calendar는 내 Google 계정의 일정과 할일을 보여 주고, 보이는 그 자리에서 바로 바꿀 수 있게 해 줍니다.

일정과 할일을 함께

월·주·일 보기와 미니 달력을 제공합니다. Google 캘린더 일정과 Google Tasks 할일이 나란히 보이고, ‘예정 작업 및 일정’ 목록이 마감까지 남은 날(D-2, D-8 …)을 알려 줍니다.

브라우저 없이 바로 편집

앱에서 일정과 할일을 추가·수정·복제·삭제합니다. 항목을 다른 날짜로 끌어 옮기고, 주·일 보기에서는 아래 끝을 끌어 시간 길이를 바꿉니다. 체크박스를 누르면 할일이 완료됩니다.

매월 반복 할일

‘매월 15일’이나 ‘매월 셋째 수요일’처럼 1~60개월 동안 반복합니다. 달마다 Google 할일을 하나씩 만들고, 수정할 때는 이 할일만 바꿀지 이후 할일까지 바꿀지 고를 수 있습니다.

여러 Google 계정

회사 계정과 개인 계정을 함께 추가하고, 계정 카드에서 바로 전환합니다.

오프라인에서도

인터넷 연결이 끊겨도 마지막으로 동기화한 일정과 할일이 화면에 그대로 남아 있습니다.

라이트·다크, 늘 가까이

라이트 또는 다크 테마를 고를 수 있습니다. Windows와 함께 시작할 수 있고, 창을 닫으면 시스템 트레이에서 기다립니다.

Google 데이터

Desk Calendar가 Google 데이터를 쓰는 방식

Desk Calendar는 내 캘린더와 할일을 보여 주고 편집하는 데 필요한 만큼만 Google 계정 접근 권한을 요청합니다. 앱은 내 PC에서 실행되며 Google과 직접 통신합니다. Desk Calendar 서버가 없으므로 내 데이터는 개발자에게 전달되지 않습니다.

Google 캘린더

auth/calendar

캘린더와 일정을 보여 주고, 앱에서 일정을 만들거나 바꾸거나 옮기거나 삭제하면 그대로 Google 캘린더에 반영합니다.

Google Tasks

auth/tasks

할일 목록과 할일을 보여 주고, 앱에서 할일을 만들거나 수정·완료·삭제하면(직접 설정한 매월 반복 할일 포함) 그대로 Google Tasks에 반영합니다.

이름과 이메일 주소

openid · email · profile

어떤 Google 계정으로 로그인했는지 보여 주고, 여러 계정을 서로 구분합니다.

내 PC에만 저장

  • 로그인 토큰 (Windows 데이터 보호 API(DPAPI)로 암호화)
  • 일정과 할일의 오프라인 사본
  • 앱 설정

하지 않는 일

  • 개발자나 Google 이외의 곳으로 데이터 전송
  • 데이터 판매, 광고에 사용
  • AI·머신러닝 모델 학습에 사용
  • 앱 안에서 사용 통계 수집이나 추적

내가 관리

  • 로그아웃하면 토큰과 오프라인 사본이 PC에서 삭제됩니다
  • 언제든 Google 계정에서 앱의 접근 권한을 해제할 수 있습니다
  • Google 계정이 없어도 로컬 모드로 쓸 수 있습니다. 모든 데이터는 PC에만 저장됩니다

Desk Calendar가 Google API에서 받은 정보를 사용하거나 다른 앱으로 전송할 때는 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

Desk Calendar 받기

필요한 것

  • Windows 10 또는 11 (64비트)
  • .NET 11 Desktop Runtime. 없다면 Microsoft에서 설치하거나 다음 명령을 실행하세요. 
    winget install Microsoft.DotNet.DesktopRuntime.11
  • Google 계정. Google 캘린더·Tasks와 동기화할 때 필요합니다. 없으면 로컬 모드로 쓸 수 있습니다.

설치와 로그인

  1. GitHub Releases에서 최신 버전을 내려받습니다.
  2. zip 파일을 원하는 폴더에 풀고 desk-calendar.exe를 실행합니다.
  3. 왼쪽의 Google 로그인을 누르면 브라우저에서 Google 로그인 페이지가 열리고, 로그인을 마치면 앱으로 돌아옵니다. Desk Calendar는 내 비밀번호를 볼 수 없습니다.
